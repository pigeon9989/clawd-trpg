# 잿빛 변경 — 세계 문서 목차 {#top}

GM 미미짱이 처음 읽는 안내. 세계 문서가 어디에 무엇을 두었는지, 캠페인이 어떻게 흐르는지, 자주 꺼내는 구역이 어디인지 적는다.
꺼내 읽는 법은 `lore(ref: "파일id#앵커")`, 찾기는 `lore(query: "낱말")`. 문서 형식은 → format#top.

- **기준**: 지명 · 인물 · 연도 · 숫자가 어긋나면 바이블(→ bible#top)이 맞고, 규칙 숫자는 핵심 규칙(→ core#top)이 맞다.
- **처음 게임을 열 때**: 바이블의 톤(→ bible#tone) → 핵심 규칙의 판정(→ core#roll) → 캐릭터 만들기(→ classes#create) → 1장 시작(→ ch1#start).
- **이어 할 때**: `status` 로 상태를 보고, 지금 장의 문서와 시계(→ #clocks)를 다시 읽는다.

## 규칙 {#rules}

| 파일 id | 무엇 |
| --- | --- |
| core | 핵심 규칙: 판정 · 기본 기술 · 이 세계의 기술(시간 모래 · 종 · 굳음) · 길과 쉼 · 피해와 방어 · 상태이상 · 시계 · 하루의 때 · 레벨 업 · 몬스터 기준 |
| gm | GM 원칙 · GM 의 수 · 위협 운영 · 단서 설계 · 장면 짜기 · NPC 연기 · 도구로 한 턴 돌리기 |
| classes | 직업 여섯(전사 · 도적 · 마법사 · 성직자 · 레인저 · 음유시인): 숫자 · 기술 · 배경 · 유대 · 시작 장비 |
| magic | 주문 걸기 · 마법사 주문 · 성직자 주문 · 모래술(시간 마법) · 마법 물건 |
| gear | 돈 · 무기 · 갑옷과 방패 · 소모품 · 서비스 · 고용인 · 탈것 · 시간 거래 |

꼭 기억할 숫자:

- **시간 모래**: 패널 소지품 `시간 모래`, 수는 꼬집. 1 꼬집 = 약 30 알 = 한 달, 12 꼬집 = 1 줌 = 1년(→ core#time-sand). 장막 안 왕도에선 한 사람이 한 때에 1 줌을 숨으로 태운다(→ serenia#rule-breath, ch5#breath).
- **방어**: 갑옷 + 방패(방패는 +1). 전사는 사슬갑옷 1 + 방패 1 = 2(→ gear#armor, gear#shield).
- **주문 수**: 마법사 · 성직자 모두 레벨+2. 소마법 · 기도는 세지 않는다(→ magic#wizard-prep, magic#cleric-communion).
